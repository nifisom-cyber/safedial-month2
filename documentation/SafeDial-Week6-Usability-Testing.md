
# SafeDial — Week 6 Usability Testing Report

## 1. Introduction

Usability testing helps us understand whether
people can use our website easily.

For SafeDial, we want to make sure users can
find emergency contact numbers quickly and
use the website without confusion.

## 2. Purpose of the Test

The purpose of this test is to:

- Check whether SafeDial is easy to navigate.
- Find out whether users can search for emergency services.
- Test whether the Copy Number button works.
- Check whether the subscription form is easy to complete.
- Identify problems that need improvement.

## 3. Target Users

We plan to test SafeDial with:

- Students
- Parents and families
- Employees
- Community members

## 4. Testing Status

This document is currently a testing plan.

Real user feedback and results will be added
after the usability tests are completed.

## 5. Usability Testing Tasks

We will ask users to complete the following tasks:

### Task 1: Find an Emergency Number
- Open the SafeDial website.
- Go to Emergency Services.
- Find the Police emergency number.

### Task 2: Search for Emergency Services
- Type "Ambulance" in the search box.
- Check whether the correct service appears.
- Click Clear Search.

### Task 3: Copy an Emergency Number
- Find the Police emergency number.
- Click Copy Number.
- Paste the number into Notepad.

### Task 4: Navigate the Website
- Visit the Home page.
- Open Safety Tips.
- Navigate to the About page.

### Task 5: Test the Subscription Form
- Open the Subscribe page.
- Enter a test email address.
- Select an audience group.
- Tick the consent checkbox.
- Click Subscribe Now.
- Check whether the demo success message appears.

## 6. What We Will Observe

During testing, we will check:

- Can users complete each task?
- Do users understand the instructions?
- Are there any errors or confusing sections?
- Is the website easy to use on a mobile phone?
- What improvements do users suggest?
