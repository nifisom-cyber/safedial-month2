
# SafeDial — Week 6 A/B Testing Plan

## 1. Introduction

A/B testing means comparing two versions of a website element to find out which one performs better.

For SafeDial, we want to test two different subscription button messages.

## 2. What We Are Testing

Version A: Subscribe Now

Version B: Get Safety Tips

Both buttons will have the same colour, size, and design. Only the text will change.

## 3. Our Hypothesis

We believe Version B ("Get Safety Tips") may encourage more visitors to click because it clearly explains what they will receive.

## 4. Our Goal

Our goal is to find out which button message encourages more visitors to click and complete the subscription demonstration.

## 5. How We Will Measure Success

We will compare Version A and Version B using:

1. Button Clicks:
   How many visitors click each button.

2. Conversion Rate:
   The percentage of visitors who successfully
   complete the subscription demonstration.

3. User Feedback:
   Which button message visitors find easier
   to understand.

## 6. Testing Method

We plan to show Version A to one group of users
and Version B to another group.

Both groups should have similar conditions.

We will compare the results to see which
button performs better.

## 7. Current Status

This is a planned A/B test.

No real visitor data has been collected,
and no winning version has been selected.

## A/B Testing Evidence and Evaluation

### Version A — Original CTA

Button Text: Subscribe Now

Purpose:
Encourage visitors to subscribe to SafeDial.

### Version B — Alternative CTA

Button Text: Get Safety Tips

Purpose:
Encourage visitors to access safety-related content
by explaining the benefit more clearly.

### A/B Testing Hypothesis

Changing the button text from "Subscribe Now"
to "Get Safety Tips" may encourage more visitors
to click because the message is clearer.

### Proposed Testing Method

1. Show Version A to one group of visitors.
2. Show Version B to another group of visitors.
3. Measure the number of clicks on each button.
4. Calculate the click-through rate for each version.
5. Compare the results to identify the better CTA.

### Success Measurement

Primary KPI: CTA click-through rate

Formula:
CTA Click-Through Rate =
(Number of CTA Clicks / Number of CTA Views) x 100

### Implementation Status

Version B ("Get Safety Tips") was implemented
on the SafeDial subscription page.

Version A ("Subscribe Now") was the original
button text.

A live A/B experiment has not yet been conducted.

No actual conversion results have been collected.

### Conclusion

Version B communicates the benefit of the
button more clearly.

However, without a live A/B test, we cannot
confirm that Version B performs better.

A future experiment could compare both versions
using real visitor data.
